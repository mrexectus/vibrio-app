# 🔮 Vibrio - Yapay Zeka Destekli İlişki Analisti

Vibrio, Jungiyen psikoloji ve gelişmiş astroloji algoritmalarını kullanarak ilişkileri analiz eden modern bir web uygulamasıdır.

## 🚀 TEK TIKLA YAYINA AL (ÖNERİLEN)

Aşağıdaki butona bastığında, Vercel sana otomatik olarak **Shopier Linkini** ve **Google API Anahtarını** soracak. Bilgileri girip "Deploy" demen yeterli!

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fvibrio-app%2Fvibrio&env=VITE_GOOGLE_API_KEY,VITE_SHOPIER_PRODUCT_LINK)

---

### 🚨 KRİTİK SON ADIM (UNUTMA!)
Müşterinin ödeme yaptıktan sonra siteye dönüp raporu görebilmesi için:

1.  **Shopier Paneline** giriş yapın.
2.  **Mağaza Ayarları** > **Geri Dönüş URL (Return URL)** alanına şunu yazın:
    `https://SENIN-SITENIN-ADRESI.vercel.app/?payment=success`
    *(Sitenin adresi Vercel kurulumu bitince belli olacak)*
    *Eğer `vibrio.info` domaini bağladıysanız: `https://vibrio.info/?payment=success`*
